# Screenshots

This folder is reserved for the project's screenshots. The READMEs (English, 中文,
Français, Deutsch, 日本語, Español) reference the following files:

| File | Content |
| --- | --- |
| `live.png` | Live WYSIWYG editing mode |
| `split.png` | Split source + preview view |
| `preview.png` | Preview-only mode |
| `formatting.png` | Bottom toolbar formatting menu |
| `webdav.png` | WebDAV sync dialog (use a **fake/example** server address) |

Tips:

- Use a phone-sized screenshot (e.g. 1080×2400) so the layout looks right.
- Do **not** include real personal notes, real server URLs, real usernames or passwords.
  Use demo content and `https://example.com` if you show the WebDAV dialog.
- After adding the files, commit them; the README tables will pick them up automatically.
